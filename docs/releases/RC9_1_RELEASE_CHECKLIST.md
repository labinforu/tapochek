# Подготовка GitHub Release v0.7.8-rc9.1

**Статус:** подготовка. Пока здесь не подтверждена публикация нового Windows Setup, действующим публичным выпуском остаётся RC8.

## Параметры релиза

- Репозиторий: `labinforu/tapochek`.
- Тег: `v0.7.8-rc9.1` (создаётся от актуальной ветки `main`, если тег ещё не существует).
- Название: **Тапочек 0.7.8 RC9.1 — статистика АРП, сохранность методов и обновления**.
- Тип: **Set as a pre-release**.
- Текст для поля Describe this release: [v0.7.8-rc9.1.md](v0.7.8-rc9.1.md) — скопировать содержимое Markdown целиком.
- Assets: `Tapochek-0.7.8-rc9.1-Setup.exe` и `Tapochek-0.7.8-rc9.1-Setup.exe.sha256` (имена должны соответствовать файлам, созданным сборщиком).

## Перед созданием релиза

1. Собрать EXE на Windows из утверждённого Windows Builder 0.7.8-rc9.1.
2. Проверить в `release/build-report.json` номер версии и успешность проверок; сверить SHA-256 с самим EXE.
3. Испытать установку и обновление поверх RC8 **на копии** пользовательских данных; проверить сохранение проектов и справочников.
4. Проверить импорт и экспорт тестовой ОА в официальном Конфигураторе ФСА, включая исторические структуры методов.
5. Проверить работу статистики на реальном АРП (авторизация, ответ сервера, серверная политика доступа, недоступность сети). Если серверный модуль ещё не введён в эксплуатацию, не обещать работающую статистику без оговорки.
6. Проверить текст лицензионного соглашения, уведомления о сторонних компонентах, отсутствие собственных исходников в установщике.

## Создание

1. Открыть https://github.com/labinforu/tapochek/releases/new под `labinforu`.
2. В `Choose a tag` вписать `v0.7.8-rc9.1`, выбрать создание нового тега.
3. Указать название из блока выше; скопировать Markdown из `v0.7.8-rc9.1.md` в описание.
4. Отметить **Set as a pre-release**.
5. Прикрепить оба файла: Setup и его `.sha256`; не загружать архив с исходниками/Builder.
6. Нажать **Save draft** и перепроверить описание и файлы. После приёмки — **Publish release**.

## После публикации

- Проверить https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc9.1 из окна без авторизации.
- Проверить скачивание и SHA-256 опубликованного EXE.
- Обновить `README.md` и `INSTALL.md`: текущую версию, ссылки, ограничения АРП и новые функции. До публикации оба файла должны продолжать указывать на RC8.
- Не удалять выпуск RC8: он остаётся доступен для отката.
