# История выпусков «Тапочка»

## [0.7.8 RC9.1](https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc9.1) — 19 ноября 2026

- Панель сравнительной статистики АРП для выбранного НД (методики) с ограничениями охвата и предварительным просмотром справочных значений.
- Дополнительная защита исторических связей методов и контроль сохранности при экспорте ОА.
- Ручная и фоновая проверка обновлений GitHub с контролем SHA-256 и выбором канала.
- Подробное описание и предупреждения: [материалы RC9.1](docs/releases/v0.7.8-rc9.1.md).

## [0.7.8 RC8](https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc8) — 15 октября 2026

- Первый публичный предварительный выпуск для Windows.
- Редактирование ОА, локальный аудит, импорт/экспорт для официального конфигуратора.
- Встроенные справочники и локальный поисковый индекс.

«Тапочек» — независимое программное обеспечение. Полученные файлы ОА проверяйте в официальном Конфигураторе Росаккредитации.
