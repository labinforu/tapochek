# Установка «Тапочка» (Windows)

Актуальный опубликованный выпуск: **[0.7.8 RC9.1 — Pre-release](https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc9.1)**. [Предыдущая RC8](https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc8) остаётся доступна.

> «Тапочек» распространяется бесплатно. Исходный код программы не публикуется. Официальный источник установщика — GitHub-репозиторий `labinforu/tapochek`.

## 1. Скачать программу

- **[Tapochek-0.7.8-rc9.1-Setup.exe](https://github.com/labinforu/tapochek/releases/download/v0.7.8-rc9.1/Tapochek-0.7.8-rc9.1-Setup.exe)** — установщик Windows 10/11 x64.
- [Tapochek-0.7.8-rc9.1-Setup.exe.sha256](https://github.com/labinforu/tapochek/releases/download/v0.7.8-rc9.1/Tapochek-0.7.8-rc9.1-Setup.exe.sha256) — контрольная сумма.
- [Описание изменений RC9.1](https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc9.1).

Отдельная установка Python пользователю не нужна. Для хранения локального индекса справочников рекомендуется иметь около 2 ГБ свободного места в пользовательском профиле; дополнительно потребуется место для самой установленной программы. Фактические требования могут зависеть от версии и объёма пользовательских данных.

## 2. Проверить файл перед запуском

Откройте PowerShell в папке, где сохранён установщик, и выполните:

```powershell
Get-FileHash -Path ".\Tapochek-0.7.8-rc9.1-Setup.exe" -Algorithm SHA256
```

Для опубликованного установщика версии 0.7.8 RC9.1 GitHub указывает SHA-256:

```text
7ce4d5a8695e170107226083ac77d53c336fb6a96c3c6938b690c5a1cb6a214a
```

Полученное значение должно совпадать с указанным выше и с содержимым прилагаемого файла `.sha256`. Если контрольные суммы не совпадают, **не запускайте файл**.

Если Windows показывает предупреждение SmartScreen о неизвестном издателе, сначала проверьте источник и целостность скачанного файла. Не отключайте защиту операционной системы ради установки.

## 3. Установить программу

1. Запустите проверенный установщик `Tapochek-0.7.8-rc9.1-Setup.exe`.
2. Ознакомьтесь с пользовательским лицензионным соглашением и продолжите установку при согласии с ним.
3. Завершите установку согласно подсказкам мастера.
4. Запустите «Тапочек» через созданный ярлык.

## 4. Первый запуск

- При первом запуске автоматически подключаются включённые в комплект справочники и распаковывается подготовленный локальный поисковый индекс. Дождитесь завершения этого процесса.
- В программу включены справочники НД, методов испытаний, показателей, единиц измерения, ОКПД2 и ТН ВЭД ЕАЭС. Дополнительно в комплекте используются вспомогательные встроенные данные программы.
- **Не закрывайте консольное окно во время работы:** оно обслуживает локальный сервер приложения.
- Для работы с уже имеющимися локальными данными постоянный интернет не требуется.

Справочные данные зафиксированы по состоянию пользовательской библиотеки на **23 сентября 2026 года**; они могут содержать устаревшие или неполные идентификаторы и автоматически через интернет не обновляются.

## 5. Обновления, статистика АРП и работа с данными

В RC9.1 появилась проверка новых версий GitHub. Пользователи RC8 должны перейти на RC9.1 вручную. После установки новой версии для получения следующих предварительных выпусков выбирайте канал обновлений с предварительными версиями.

Статистика АРП доступна отдельно от локального аудита и требует соединения с сервером и учётной записи АРП. В RC9.1 отчёт по пунктам ОА использует выборку до **100 пунктов**, а выдачи некоторых категорий ограничены первыми 100 результатами. Статистика отражает частоту встречаемости значений, не подтверждает их нормативную правильность и не гарантирует полноту охвата.

Обратите внимание на исторические идентификаторы: при открытии старой ОА наименования методов, методик и показателей могут отличаться от сведений в текущих справочниках. Перед заменой проверяйте применимость записи и её связи.

Планируемые изменения доступа к статистике после 24 декабря 2026 года потребуют соответствующей серверной реализации в АРП; локальные бесплатные функции «Тапочка» от этого не зависят.


Перед обновлением или удалением программы рекомендуется сохранить копии важных проектов и исходных документов. Не полагайтесь на то, что переустановка всегда сможет восстановить данные после нештатного сбоя.

Рабочие результаты редактирования и экспортированные файлы проверяйте в **официальном Конфигураторе областей аккредитации Росаккредитации**. Независимая программа не гарантирует полной совместимости с любыми версиями официального ПО.

Подробнее об источниках данных: [Источники данных и особенности совместимости](DATA_SOURCES_AND_LIMITATIONS.md).
