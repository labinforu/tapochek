# Установка «Тапочка»

> **Статус:** первый публичный установщик ещё готовится. Данная инструкция предварительная и будет уточнена после проверки финальной сборки.

## Где скачать

Официальное место публикации бесплатных установщиков — раздел [Releases](https://github.com/labinforu/tapochek/releases) этого репозитория.

До выхода первого релиза скачивать пока нечего. Не используйте файлы, выдаваемые сторонними сайтами за установщик «Тапочка».

## Как установить после выхода релиза

1. Откройте [Releases](https://github.com/labinforu/tapochek/releases).
2. Выберите нужный выпуск и прочитайте примечания к нему, включая сведения о поддерживаемых версиях Windows и известных ограничениях.
3. Скачайте указанный в выпуске установщик Windows (файл `.exe`) из блока **Assets**.
4. При наличии опубликованной контрольной суммы SHA-256 сравните её с хешем скачанного файла.
5. Запустите проверенный установщик и следуйте его инструкциям.
6. После установки выполните первичную проверку на тестовых, не содержащих конфиденциальной информации данных.

**Важно:** требования к системе, необходимость дополнительных компонентов, точный порядок установки и обновления будут подтверждены для конкретного релиза. Пока не следует считать их установленными.

### Проверка контрольной суммы в Windows

Откройте PowerShell в папке с загруженным файлом и выполните:

```powershell
Get-FileHash -Path ".\ИМЯ_СКАЧАННОГО_ФАЙЛА.exe" -Algorithm SHA256
```

Вместо `ИМЯ_СКАЧАННОГО_ФАЙЛА.exe` укажите настоящее имя установщика. Сравните результат со значением, опубликованным в описании релиза. Если хеши отличаются, не запускайте файл.

Если Windows показывает предупреждение безопасности, сначала проверьте происхождение установщика и сведения о выпуске. Не отключайте защиту Windows только ради установки.
