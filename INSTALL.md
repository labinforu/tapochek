# Установка «Тапочка» (Windows)

Актуальный опубликованный выпуск: **[0.7.8 RC8 — Pre-release](https://github.com/labinforu/tapochek/releases/tag/v0.7.8-rc8)**.

> «Тапочек» распространяется бесплатно. Исходный код программы не публикуется. Официальный источник установщика — GitHub-репозиторий `labinforu/tapochek`.

## 1. Скачать программу

- **[Tapochek-0.7.8-rc8-Setup.exe](https://github.com/labinforu/tapochek/releases/download/v0.7.8-rc8/Tapochek-0.7.8-rc8-Setup.exe)** — установщик для Windows 10/11 x64.
- [Tapochek-0.7.8-rc8-Setup.exe.sha256](https://github.com/labinforu/tapochek/releases/download/v0.7.8-rc8/Tapochek-0.7.8-rc8-Setup.exe.sha256) — контрольная сумма.

Отдельная установка Python пользователю не нужна. Для хранения локального индекса справочников рекомендуется иметь около 2 ГБ свободного места в пользовательском профиле; дополнительно потребуется место для самой установленной программы. Фактические требования могут зависеть от версии и объёма пользовательских данных.

## 2. Проверить файл перед запуском

Откройте PowerShell в папке, где сохранён установщик, и выполните:

```powershell
Get-FileHash -Path ".\Tapochek-0.7.8-rc8-Setup.exe" -Algorithm SHA256
```

Для опубликованного установщика версии 0.7.8 RC8 GitHub указывает SHA-256:

```text
d4bc632415c3157a72239e2e39dc5a7054de53929ea852397963bac032138e47
```

Полученное значение должно совпадать с указанным выше и с содержимым прилагаемого файла `.sha256`. Если контрольные суммы не совпадают, **не запускайте файл**.

Если Windows показывает предупреждение SmartScreen о неизвестном издателе, сначала проверьте источник и целостность скачанного файла. Не отключайте защиту операционной системы ради установки.

## 3. Установить программу

1. Запустите проверенный установщик `Tapochek-0.7.8-rc8-Setup.exe`.
2. Ознакомьтесь с пользовательским лицензионным соглашением и продолжите установку при согласии с ним.
3. Завершите установку согласно подсказкам мастера.
4. Запустите «Тапочек» через созданный ярлык.

## 4. Первый запуск

- При первом запуске автоматически подключаются включённые в комплект справочники и распаковывается подготовленный локальный поисковый индекс. Дождитесь завершения этого процесса.
- В программу включены справочники НД, методов испытаний, показателей, единиц измерения, ОКПД2 и ТН ВЭД ЕАЭС. Дополнительно в комплекте используются вспомогательные встроенные данные программы.
- **Не закрывайте консольное окно во время работы:** оно обслуживает локальный сервер приложения.
- Для работы с уже имеющимися локальными данными постоянный интернет не требуется.

Справочные данные зафиксированы по состоянию пользовательской библиотеки на **23 сентября 2026 года**; они могут содержать устаревшие или неполные идентификаторы и автоматически через интернет не обновляются.
